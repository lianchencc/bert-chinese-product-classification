# Data

The datasets used in this project are not included in this public repository.

Expected files:

| File | Description | Columns used |
|------|-------------|--------------|
| `shopee_item_category.csv` | Labeled Shopee product titles (~253k rows) used for training and testing | `商品名稱`, `大類`, `小類` |
| `jambo_4.csv` | Unlabeled product list (~18.7k rows) classified by the trained model | `商品名稱` |

Place the files in this `data/` folder before running the notebook.
